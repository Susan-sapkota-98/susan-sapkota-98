### 1. Nepali Speech Recognition with Whisper

[Repository](https://github.com/Susan-sapkota-98/Nepali-Whisper-ASR)

An experiment on fine-tuning Whisper for Nepali speech recognition.

I wanted to understand how much training data is needed to improve speech recognition for Nepali. I fine-tuned Whisper-small using different amounts of training data and compared the results.

Some things I worked on:
- Preparing and splitting the speech dataset by speaker.
- Fine-tuning Whisper-small.
- Evaluating the model using Word Error Rate (WER) and Character Error Rate (CER).
- Comparing results with different training data sizes.
- Listening to incorrect predictions and studying common errors.

In my current experiment, the model trained with 7,961 clips achieved a CER of 0.104 on 898 test clips.

This project helped me understand model evaluation, dataset preparation, and the importance of examining errors instead of looking only at the final score.

### 2. Corrective RAG (CRAG)

[Repository](https://github.com/Susan-sapkota-98/CRAG)

A document question-answering project that explores retrieval improvement and OCR.

The application is designed to work with documents and images, including scanned documents. I'm exploring how retrieval quality affects the answers generated by an LLM.

Things I have worked on:
- Document processing and text extraction.
- Vector search using FAISS.
- LangChain and LangGraph workflows.
- OCR for printed Nepali and English text.
- A separate OCR approach for English handwritten documents.
- Retrieval evaluation and web search refinement.

I'm still improving this project and its evaluation.

### 3. AI Data Agent

[Repository](https://github.com/Susan-sapkota-98/AI-Data-Agent)

This project explores how an AI agent can help with database queries and data processing.

I used LangGraph to create a workflow that routes user requests to different agents.

The current implementation includes:
- Routing user requests to SQL or ETL workflows.
- Generating PostgreSQL queries from natural language questions.
- Using database schema information as context.
- Extracting data from API endpoints.
- Transforming data using Python and Pandas.

Through this project, I'm learning about agent workflows, database interaction, and the challenges of executing LLM-generated operations safely.
